# MDpentagon

録音した音の一部分を5要素で可視化し、日常での活用候補を表示するスマートフォン向け試作アプリです。

## 使い方

1. HTTPSで配信されたページをスマートフォンで開く
2. 「録音をはじめる」を押してマイクを許可する
3. 別の端末やスピーカーで曲を流し、8〜20秒録音する
4. 五角形の分析結果と活用候補を確認する

## 注意

- 数値は端末のマイクから取得した音を簡易的な音響計算で分析したものです。
- 曲の良し悪し、医療効果、学習効果を判定するものではありません。
- 録音データはサーバーへ送信せず、端末内だけで処理します。
- マイク機能にはHTTPS環境が必要です（開発時のlocalhostを除く）。
